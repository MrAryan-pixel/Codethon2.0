Encapsulation
The bundling of data (attributes) and methods (functions) that operate on the data into a single unit (class), while restricting direct access to internal state using access specifiers (private, protected).
Abstraction
The practice of exposing only essential features and interface details to the outside world while hiding internal implementation and background complexity.
Inheritance
The mechanism where a new class (derived/child class) acquires the properties and behaviors of an existing class (base/parent class), promoting code reusability.
Polymorphism
The ability of an entity (such as a function, method, or operator) to take multiple forms—allowing different underlying classes to be accessed through the same interface (e.g., method overloading and method overriding).
Class
A blueprint or template that defines the variables and methods common to all objects of a certain kind.
Object
A real-world instance of a class that holds actual values and allocates memory at runtime.
